参考度の星について

原産地の気候を栽培の参考にしやすい度合いを、編集上の暫定評価で示します。耐寒性・栽培可否の判定ではありません。

  1. ★1：原種未特定／日長などの改良の影響が大きい
  2. ★2：抽苔・結球などの品種特性を優先
  3. ★3：広い分布・栽培化・未評価の園芸改良に注意
  4. ★4：原種の地域を比較の手がかりに（暫定）
  5. ★5：栽培資料でも基本的な温度・水分の傾向を確認

栽培種・広い分布・野菜/草花は★3、その他は★4を基本とし、個別資料がある植物は理由に応じて調整しています。★4・5でも地点の標高や品種別の耐寒性は別に確認してください。

データと利用上の注意

日本の気温（平均・最高・最低）・降水量・日射量は、気象庁の日別平年値と既存の月別1kmメッシュを基にした1991–2020年の独自推定値です。日本の相対湿度は1991–2020年の観測所の日平均値と公式の月別平年値から独自推定した約1km値です。いずれも気象庁が公表する公式の1km日別平年値ではありません。地図の広域表示は概要画像で、拡大時には1km格子の値を再描画します。観測所から遠く推定できない格子は欠測とし、NASA値では埋めません。

日本以外の気候データ：NASA Langley Research Center POWER Project。全球分布図は公開AWS Zarrの月別データから独自集計し、地点詳細はClimatology API / Daily APIから取得しています。降水量は日平均量に各月・年の日数を掛けて月降水量・年降水量へ換算しています。NASAは本ツールを承認または推奨するものではありません。

地図の枠（地点Aは青・比較Bは橙）は、日本の有効なメッシュ内では約1kmの3次メッシュ、日本以外ではNASA POWER気象格子の中心に合わせた約0.5°×0.625°の範囲です。白い小点は格子中心です。日本以外の気温・降水量・相対湿度は選択した枠に対応する元格子の空間平均です。日射量は同じ中心点に対応する別の1°×1°格子です。日本の湿度は独自推定の約1km値です。

気候区分：Beckほか（2023）ケッペン＝ガイガー気候区分の1991–2020年・0.1°版（CC0）をWebメルカトルへ再投影しています。区分境界付近には不確実性があります。

地図境界・国名・周辺都市：Natural Earth 1:50m Admin 0 Countries / 1:10m Populated Places Simple v5.1.2（Public Domain）。格子中心が属する国・地域と、主要都市・行政中心点からの概算位置を表示します。行政区画の判定ではなく、境界・名称表示は法的立場を示すものではありません。

本ツールは広域の気候傾向を確認する試作版です。日本の約1kmは格子の大きさであり、実測精度を意味しません。特に日射は利用できる観測所が少なく、地形・沿岸・都市の細かな差も再現しません。栽培可否の断定には使用しないでください。

プライバシー

Cookie、アクセス解析、現在地取得、入力情報の保存は行いません。比較基準はページを開いている間だけ保持し、再読み込みで消去されます。日本のメッシュをクリックしてもNASA POWERへは接続しません。日本以外の地点をクリックすると、気象格子の中心座標と通常の通信情報がNASA POWERへ送信されます。
